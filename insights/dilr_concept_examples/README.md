Welcome to the **Intuitive DILR Concept & Grid-Evolution Examples Bank** (`insights/dilr_concept_examples/`).

Beginners often struggle in DILR because standard solutions only show the **finished table**, hiding *how* to draw the initial grid, *which* clue to pick first, and *how* the table evolves step by step. Every concept and mathematical invariant across all 6 DILR modules is unpacked here using a **5-Part Grid-Evolution Learning Template**:

1. **Concept & Invariant in Plain English**: What the rule or mathematical invariant means without jargon and why it works.
2. **When to Use It (Set / Question Cue)**: The exact wording or visual structure in a DILR prompt that triggers this method.
3. **General Mini-Set Example (Clean Numbers, Single Concept)**: A bite-sized, self-contained 3-to-4 clue puzzle isolating just that one mechanism.
4. **Step-by-Step Grid Evolution (Two Ways)**:
   - **Stage 0 (Empty Scratchpad Grid) $\to$ Stage 1 (Anchor Clue Lock) $\to$ Stage 2 (Deduction Squeeze) $\to$ Final Locked Grid**
   - **30-Second Invariant / Ratio Shortcut**: How to answer the question directly using conservation laws without filling every cell.
5. **The 1 Common Mistake to Avoid**: The #1 grid-drawing error or wording trap that wastes 10+ minutes in the exam hall.
