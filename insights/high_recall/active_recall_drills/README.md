# CAT High-Recall Active-Recall Drills & Speed Execution Playbooks

> **Navigation**: [Master CAT Study Roadmap (`../../CAT_Study_Roadmap_and_Flow.md`)](../../CAT_Study_Roadmap_and_Flow.md) | [Study Tracker & Error Log (`../../Study_Tracker_and_Error_Log.md`)](../../Study_Tracker_and_Error_Log.md) | [Cheat Sheets (`../cheat_sheets/`)](../cheat_sheets/) | [Anki Flashcards (`../anki_flashcards.csv`)](../anki_flashcards.csv)

This folder contains **timed, interactive active-recall drills** designed to train the three highest-leverage exam-hall reflexes in CAT:
1. **Mental Calculation & DI Ratio Comparison Speed** (eliminating on-screen calculator dependency),
2. **20-Second QA `Round_1_Sitter` Trigger Recognition** (spotting the shortcut before writing algebra),
3. **4-Minute DILR Set Selection & Anchor Lock** (classifying Bucket A/B/C sets and picking the first clue), and
4. **10-Second VARC 2-Option Showdown Tie-Breaking** (tagging the exact mechanical flaw in the losing contender).
