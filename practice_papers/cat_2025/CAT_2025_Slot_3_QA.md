<details><summary><b>Verified Answer & Dual-Method Solution (First-Principles + 30s Shortcut + Trap Alert)</b></summary>

- **Verified Answer**: **`(C) 811`**
- **Quick Derivation Summary**: For 4-digit number THXU: T + H + X = 15, H + X + U = 16 => U = T + 1 (with T >= 1), and X = U + 6 = T + 7 <= 9 => T in {1, 2}. For T = 1: 1682; for T = 2: 2493. Difference = 2493 - 1682 = 811.
- **Method 1 — First-Principles Derivation**: Let the digits be T, H, X, U. From U - T = 1 and X = U + 6, we have U = T + 1, X = T + 7, and H = 15 - T - (T + 7) = 8 - 2T. Since T >= 1 and X <= 9, T can only be 1 (number = 1682) or 2 (number = 2493). Difference = 2493 - 1682 = 811.
- **Method 2 — 30-Second Exam-Hall Speed Shortcut**: Increasing T by 1 changes H by -2, X by +1, U by +1, so the 4-digit number changes by 1000(1) + 100(-2) + 10(1) + 1(1) = 811!
- **Trap Alert & Boundary Condition**: T >= 1 since the number is greater than 1000 (so T = 0 giving 0871 is excluded).
