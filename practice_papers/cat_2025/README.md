This directory contains all **9 official CAT 2025 sectional papers** (Slots 1, 2, and 3 across VARC, DILR, and QA — $68 \times 3 = 204$ questions in total) formatted as **spoiler-free interactive practice papers**. Every question includes:
1. Full passage / set / question text (with restored LaTeX equations),
2. A collapsible **`Hint (Topic, Difficulty, Round Tag & Mental Trigger)`** dropdown so you can nudge yourself without seeing the answer, and
3. A collapsible **`Verified Answer & Dual-Method Solution`** dropdown containing both the **First-Principles Derivation**, the **30-Second Exam-Hall Speed Shortcut**, the **Trap Alert**, and direct links to the matching study modules.

## How to Take a Timed 40-Minute Sectional Paper

1. **Open Both the PDF (for Charts/Diagrams) and the Interactive Markdown Paper**:
   - Keep the clean PDF from [`../../docs/pyqs/2025/`](../../docs/pyqs/2025/) open alongside the `.md` paper so any visual DI charts or geometry diagrams are visible while all collapsible answers stay hidden.
2. **Enforce Strict 40-Minute Sectional Discipline**:
   - **VARC (40 mins)**: $26\text{ mins}$ for $4$ RC passages ($6.5\text{ mins/passage}$) $+$ $14\text{ mins}$ for $8$ VA questions.
   - **DILR (40 mins)**: First $4\text{ mins}$ to scan all $5$ sets and rank Bucket A sitters; $10\text{–}12\text{ mins}$ per set; enforce the **6-minute bail-out rule**.
   - **QA (40 mins)**: **Pass 1 (Mins 0–22)** — sweep all 22 questions and solve every `Round_1_Sitter` in $< 90\text{s}$; **Pass 2 (Mins 22–38)** — solve `Round_2_Doable` questions; **Final 2 mins** — enter an educated integer guess on every unattempted TITA question ($0$ negative penalty!).
3. **Score & Audit in [`Study_Tracker_and_Error_Log.md`](../../insights/Study_Tracker_and_Error_Log.md)**:
   - Award **$+3$** for each correct answer, **$-1$** for each wrong MCQ, and **$0$** for wrong/unattempted TITA.
   - For every question you missed or took $> 2.5$ minutes on, open the **Hint** first to try re-solving with the `See X -> Do Y` trigger, then study the **Dual-Method Solution** and log the root cause.
